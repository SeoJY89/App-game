# Hint Room 힌트 룸 🧩

물체를 올바른 위치에 놓아 힌트를 찾고, 논리적으로 문제를 푸는 두뇌 퍼즐 게임

## How to Play

1. `index.html`을 브라우저에서 열기
2. 화면의 오브젝트를 드래그하여 빈 슬롯에 놓기
3. 올바른 위치에 놓으면 힌트가 나타남
4. 모든 힌트를 모아 문제를 풀고 정답 입력
5. 정답이면 스테이지 클리어 → 다음 스테이지로!

## Stages (10 스테이지)

| Stage | 제목 | 주제 |
|-------|------|------|
| 1 | 기호의 비밀 | 기본 덧셈 |
| 2 | 과일 저울 | 변수 추리 |
| 3 | 거울의 방 | 역전 사고 |
| 4 | 시계의 방 | 시간 계산 |
| 5 | 색 혼합 실험 | 연쇄 추론 |
| 6 | 동물 농장 | 다단계 방정식 |
| 7 | 암호 해독 | 치환 암호 |
| 8 | 마법진 | 마방진 논리 |
| 9 | 수열 추리 | 피보나치 수열 |
| 10 | 최종 관문 | 연립방정식 |

## Features

- **스테이지 기반** - 10개 스테이지, 점진적 난이도 상승
- **드래그 앤 드롭** - 오브젝트를 위치에 놓아 힌트 발견
- **논리 퍼즐** - 힌트를 조합하여 정답을 추리
- **자동 저장** - 진행 상황 localStorage 저장
- **사운드 & 파티클** - 정답/오답 피드백 효과

## Tech

- Pure HTML5 Canvas + Vanilla JavaScript
- No dependencies, no build step
- Mobile-first responsive design
