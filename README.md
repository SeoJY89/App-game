# 연기피해! - 심부름 대작전

담배연기를 피해 심부름 목적지까지 도착하는 2D 횡스크롤 아케이드 게임

## 조작법

- **PC**: 방향키 위/아래 또는 W/S
- **모바일**: 화면 스와이프 또는 우측 버튼

## 게임 규칙

- 담배 피우는 사람들의 연기를 피해 목적지까지 이동
- 연기에 닿으면 숨참기 게이지 감소
- 숨참기 게이지가 0이 되면 게임 오버
- 목적지(마트)에 도착하면 스테이지 클리어

## 스테이지

1. 우리 동네 (100m)
2. 학교 앞 거리 (150m)
3. 번화가 (200m)
4. 공사장 옆길 (250m)
5. 마트 가는 길 (300m)
