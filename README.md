# Escape - 방탈출 🔒

휴대폰 방탈출 게임 스타일의 모바일 웹 퍼즐 게임. 방 안의 물건들을 조사하고, 단서를 조합하여 탈출하세요.

## How to Play

1. `index.html`을 브라우저에서 열기
2. 방 안의 물건(아이콘)을 탭하여 조사
3. 단서를 모아 잠금장치 해제
4. 아이템을 획득하여 인벤토리에 보관
5. 인벤토리 아이템을 선택 후 물건에 사용 (조합 가능)
6. 출구를 열고 탈출!

## Features

- **5개의 방** - 점점 복잡해지는 퍼즐
- **클래식 방탈출 메커니즘** - 단서, 키패드, 아이템, 인벤토리
- **아이템 조합** - 건전지 + 손전등처럼 인벤토리 아이템 조합
- **숨겨진 단서** - 여러 번 탭해서 발견하는 숨겨진 요소
- **잠금 해제** - 키패드 코드 입력
- **자동 저장** - 진행 상황 localStorage 저장

## Stages

| Room | 제목 | 주제 |
|------|------|------|
| 1 | 교수의 서재 | 책장 / 그림 / 서랍 |
| 2 | 낡은 침실 | 침대 / 거울 / 보석함 |
| 3 | 비밀의 실험실 | 시험관 / 손전등 조합 |
| 4 | 잊혀진 도서관 | 지구본 / 두루마리 / 제단 |
| 5 | 최후의 방 | 3개 제단 / 구슬 / 최종 탈출 |

## Tech

- Pure HTML5 Canvas + Vanilla JavaScript
- No dependencies, no build step
- Mobile-first responsive design
- localStorage progress save
