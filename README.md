# Block Blast - 블록 퍼즐 게임

8x8 그리드 기반의 중독성 있는 블록 퍼즐 게임입니다.

## 게임 방법

1. 하단 트레이에서 블록을 드래그하여 보드에 배치
2. 가로 또는 세로 줄을 완성하면 줄이 사라지며 점수 획득
3. 연속으로 줄을 없애면 콤보 보너스
4. 더 이상 블록을 놓을 수 없으면 게임 오버

## 주요 기능

- **28종 블록 형태** - 다양한 전략적 배치 가능
- **콤보 시스템** - 연속 줄 클리어 시 점수 배율 증가
- **터치 최적화** - 모바일 드래그 앤 드롭
- **PWA 지원** - 홈 화면에 앱으로 설치 가능, 오프라인 플레이
- **파티클 이펙트** - 줄 클리어 시 시각적 효과
- **최고 점수 저장** - 로컬 스토리지 기반

## 기술 스택

- HTML5 Canvas (게임 렌더링)
- Vanilla JavaScript (프레임워크 없음, 빠른 로딩)
- CSS3 (애니메이션, 반응형 디자인)
- PWA (Service Worker, Web App Manifest)

## 실행 방법

```bash
# 정적 서버로 실행 (예시)
npx serve .
# 또는
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속

## 시장성 분석

- **장르**: 블록 퍼즐 (Block Blast, 1010! 등 상위 매출 앱과 동일 장르)
- **타겟**: 전 연령대, 캐주얼 게이머
- **수익 모델**: 광고 (배너/전면/리워드), 인앱 결제 (아이템/테마)
- **리텐션**: 단순하지만 중독성 있는 게임플레이
