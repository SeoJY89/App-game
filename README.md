# Mochi Pop! 모찌 팝! 🍡

귀여운 모찌를 터뜨리는 중독성 있는 캐주얼 게임

## How to Play

1. `index.html`을 브라우저에서 열기
2. 화면을 탭하여 게임 시작
3. 떠오르는 모찌를 탭해서 터뜨리기
4. 모찌를 놓치면 하트를 잃음 (3개)
5. 빠르게 연속으로 터뜨리면 콤보 보너스!

## Features

- **원탭 조작** - 누구나 쉽게 플레이
- **콤보 시스템** - 연속 팝으로 점수 배율 증가 (x2~x10)
- **피버 타임** - 특정 점수 달성 시 더블 점수
- **골든 모찌** - 희귀 등장, 고득점 기회
- **귀여운 파스텔 디자인** - 다양한 표정의 모찌 캐릭터
- **사운드 이펙트** - Web Audio API로 합성된 귀여운 효과음

## Tech

- Pure HTML5 Canvas + Vanilla JavaScript
- No dependencies, no build step
- Mobile-first responsive design
