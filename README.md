# The Line - 규칙을 발견하라 ✨

**The Witness** 스타일의 선 그리기 퍼즐 게임. 규칙은 설명되지 않습니다. 직접 관찰하고 발견하세요.

## How to Play

1. `index.html`을 브라우저에서 열기
2. **시작점(노란 동그라미)**을 누른 채 드래그
3. 선을 끝점까지 그려서 퍼즐 완성
4. 올바르면 초록빛으로 반짝, 틀리면 빨갛게 번쩍 → 다시 도전

## 규칙을 발견하세요

설명서는 없습니다. 퍼즐을 풀면서 각 기호의 의미를 스스로 깨달아야 합니다.

- **Chapter A**: 선 그리기의 기본
- **Chapter B**: 육각점의 비밀
- **Chapter C**: 흑과 백의 분리
- **Chapter D**: 쌍의 법칙
- **Chapter E**: 모든 규칙의 융합

총 15개의 퍼즐.

## Features

- **규칙 발견 시스템** - 튜토리얼 없음, 관찰로 깨우치기
- **The Witness 영감** - 선 그리기 + 다양한 기호 규칙
- **점진적 난이도** - A → E 챕터로 규칙이 쌓임
- **자동 저장** - localStorage 진행상황 저장

## Tech

- Pure HTML5 Canvas + Vanilla JavaScript
- No dependencies, no build step
- Mobile-first responsive design
