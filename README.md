# Mochi Merge! 모찌 머지! ✨

귀여운 아이템을 합쳐서 새로운 아이템을 발견하는 중독성 머지 퍼즐 게임

## How to Play

1. `index.html`을 브라우저에서 열기
2. 제너레이터 버튼을 탭하여 아이템 생성
3. 같은 아이템을 드래그해서 합치기 → 레벨업!
4. 주문에 맞는 아이템을 탭하면 납품 → 별 획득
5. 21종의 아이템을 모두 발견해보세요!

## Merge Chains

- **꽃**: 🌰→🌱→🌷→🌸→💐→🌺→🌳
- **디저트**: 🍬→🍪→🍩→🎂→🧁→🏰→🌈
- **동물**: 🥚→🐣→🐔→🐱→🐶→🦄→🐉

## Features

- **드래그 앤 드롭 머지** - 직관적인 합치기 조작
- **3개 머지 체인** - 꽃, 디저트, 동물 각 7레벨
- **주문 시스템** - 아이템 납품으로 별 보상
- **도감** - 발견한 아이템 수집
- **자동 저장** - 언제든 나갔다 돌아와도 OK
- **귀여운 파스텔 디자인** - 이모지 아이콘 + 파티클 이펙트
- **사운드 이펙트** - Web Audio API 합성 사운드

## Tech

- Pure HTML5 Canvas + Vanilla JavaScript
- No dependencies, no build step
- Mobile-first responsive design
- localStorage auto-save
